A propriedade position do css pode assumir os seguintes valores

  • static - Este é o valor padrão. O elemento posicionado de acordo com o fluxo normal do documento.
  • relative - O elemento é posicionado em relação e sua posição no fluxo normal do documento
  • fixed - O elemento é posicionado em relação o viewport.
  • absolute - O elemento é posicionado em relação ao ancestral mais proximo.
  • sticky - O elemento varia entre relative e fixed dependedo da posição da rolagem.

A posição dos elementos é definida pelas propriedades top. bottom, left e right.
